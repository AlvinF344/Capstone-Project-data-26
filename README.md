# ULB Capstone Project – Data 26

## Overview

This repository contains the work developed as part of the ULB Data Science Capstone Project (Data 26).

The project brings together different areas of data science and analytics, covering data exploration, statistical analysis, database management, data visualisation, and machine learning.

The repository is organised into four main components, each focusing on a different aspect of the data science workflow.

## Project Structure

```text
Capstone-Project-data-26/
│
├── Statistics and R/
│   └── Statistical analysis and data exploration
│
├── SQL-postgres/
│   └── Database queries and data management
│
├── Power BI/
│   └── Data visualisation and reporting
│
├── ML_capstone/
│   └── Python-based machine learning project
│
├── .gitignore
└── README.md
```

## Components

### 1. Statistics and R

Statistical analysis and exploratory data analysis using R.

This section contains the work related to statistical methods, data exploration, hypothesis testing, and visualisation.

### 2. SQL and PostgreSQL

Database management and querying using SQL and PostgreSQL.

This section covers data retrieval, manipulation, filtering, aggregation, and database-related operations.

### 3. Power BI

Data visualisation and reporting using Microsoft Power BI.

This section contains dashboards, reports, and visual representations designed to communicate insights from the data.

### 4. Machine Learning – Python

The `ML_capstone` directory contains the Python-based machine learning work.

The development environment uses Python and an isolated virtual environment to manage project dependencies.

The machine learning workflow may include:

- Data preparation and preprocessing
- Exploratory data analysis
- Feature engineering
- Model development and training
- Model evaluation and performance analysis
- Visualisation and interpretation of results

## Python Environment Setup

The Python machine learning component is maintained separately within `ML_capstone`.

### 1. Navigate to the project

```bash
cd ML_capstone
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

### 3. Activate the environment

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 4. Install dependencies

If a `requirements.txt` file is available:

```bash
python -m pip install -r requirements.txt
```
